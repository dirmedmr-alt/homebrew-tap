# Homebrew tap for AI Access Auditor

```
brew tap dirmedmr-alt/tap
brew trust dirmedmr-alt/tap
brew install --cask ai-access-auditor
```

The app shows what your AI agents (Claude Code, Codex, Gemini CLI, Cursor, OpenCode and more) can access, asks before they act, and lets you take it back. Website: https://dirmedmr-alt.github.io/ai-access-auditor/

Update with `brew upgrade --cask ai-access-auditor`. Uninstall with `brew uninstall --cask ai-access-auditor` (add `--zap` to also remove its settings and history).
